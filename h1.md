asensin ssh:n komennoilla sudo apt-get update ja sudo apt-get -y install ssh tämän jälkeen laitoin ssh:n päälle ja asetuksen niin että se käynnistyy jatkossa heti komennolla
sudo systemctl enable --now ssh
generoin ssh avainparin komennolla ssh-keygen ja kopioin sen localhostiin komennolla ssh-copy-id localhost. 
nyt käyttäessäni komentoa ssh localhost en tarvitse salasanaa sisäänkirjautumiseen.

seuraavaksi lisään hosts.ini:n [all:vars]
ansible_python_interpreter=/usr/bin/python3 jotta se ei valita pythonversiosta
luon ansible kansioon tiedoston ansible.cfg ja lisään sinne asetuksen [defaults]
inventory = hosts.ini jotta en joudu kertomaan ansible komennoille käyttämään hosts.ini tiedostoa
